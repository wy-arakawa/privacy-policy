MoonPocket 使用教程

用快捷指令把支付截图导入 App，完成识别、确认和保存。当前推荐流程分为以下 3 部分。

1. 新建快捷指令

按下面顺序添加动作，最后快捷指令里只保留这 3 个动作：截屏、将截屏拷贝至剪贴板、从剪贴板导入截图。

  1. 打开快捷指令，点右上角 + 新建。
  2. 在底部搜索操作，准备添加第一个动作。
  3. 搜索 控制，选择 截屏。
  4. 搜索并选择 拷贝至剪贴板，让它拷贝上一步的 截屏 结果。
  5. 回到操作列表，找到并点 月光钱袋。
  6. 选择 从剪贴板导入截图。
  7. 检查顺序无误后，建议关闭最后一步的 运行时显示。

2. 绑定轻点背面

把刚建好的快捷指令绑定到系统“轻点背面”，以后在支付完成页双击手机背面即可运行导入流程。

  1. 打开系统设置，在搜索框输入 触控，选择辅助功能里的 触控。
  2. 进入触控页面，向下找到 轻点背面。
  3. 选择 轻点两下；如果你习惯三下，也可以改选 轻点三下。
  4. 在快捷指令列表里选择刚创建的 记账儿。
  5. 返回轻点背面页面，确认 轻点两下 右侧已显示 记账儿。

3. 始终允许从其他 App 粘贴

第一次运行时，请在系统设置里把“从其他 App 粘贴”设为“允许”。MoonPocket 只会在你主动运行快捷指令导入截图时读取剪贴板中的截图内容，不会持续监听，也不会在后台反复读取。

这一步是为了让快捷指令把截图交给 App。不给权限时，App 无法读取刚刚复制到剪贴板的截图。

MoonPocket Tutorial

Use Shortcuts to send a payment screenshot into the app, then review and save the result. The recommended setup has 3 parts.

1. Create a Shortcut

Add the actions in this order. The final shortcut should contain only: Take Screenshot, Copy Screenshot to Clipboard, and Import Screenshot from Clipboard.

  1. Open Shortcuts and tap + in the top-right corner.
  2. Use the action search panel at the bottom.
  3. Search for Control, then add Take Screenshot.
  4. Search for and add Copy to Clipboard. Its input should be the screenshot.
  5. Go back to the action list and choose MoonPocket.
  6. Select Import Screenshot from Clipboard.
  7. Check the final order and turn off Show When Run for the last action.

2. Assign Back Tap

Bind the shortcut to iOS Back Tap so you can run the import flow by double-tapping the back of your iPhone after payment.

  1. Open iOS Settings, search for Touch, then choose Touch under Accessibility.
  2. On the Touch page, scroll down and open Back Tap.
  3. Choose Double Tap. You can choose Triple Tap instead if you prefer.
  4. In the Shortcuts list, select the shortcut you just created, such as 记账儿.
  5. Return to Back Tap and confirm Double Tap shows the shortcut name.

3. Always allow paste from other apps

When you run the shortcut for the first time, set “Paste from Other Apps” to “Allow” in iOS settings. MoonPocket reads the clipboard only when you actively run the shortcut to import a screenshot. It does not keep listening or repeatedly read clipboard contents in the background.

This permission is required so the shortcut can hand the screenshot to the app. Without it, the app cannot read the screenshot you just copied to the clipboard.
